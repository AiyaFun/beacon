# 烽火台 · 快速设置说明

先把三件事配好（①②③），再看懂每天的选题推荐（④⑤⑥）。都在左侧导航里。

> 与 `app/(app)/help/page.tsx` 内容对齐，**改一处两处都要同步**。

---

## 1️⃣ 装浏览器采集助手 —— 顺手把公开数据收进作战室

**在哪里**：左侧导航「工具 → 下载采集助手」

1. 选你的浏览器下载安装（Chrome / Edge / 360 / Brave 通用；Safari 即将支持）。
2. 到「工具 → 模型与设置 → 数据源 → 插件采集令牌」点生成，把令牌复制进插件设置页。
3. 到「情报 → 竞对监控」订阅竞对，打开对方公开主页即自动采集；在自己作品页可一键回填数据。
   **如果你有不止一个账号**：先在插件设置页把「回填到哪个账号」选好——不选的话系统只会按平台
   挑同平台里最早建的那个号，两个抖音号必然错一半，而挂错账号的数据在数据看板上一条都看不见。
4. 刷到值得记一笔的内容，点「收进灵感箱」——它会进选题池（见 ⑤）。这颗按钮在任何网页上都在。

> 只采你亲眼可见的公开数据，不后台抓取。

### 同一个号在列表里出现了两次？合并它

插件在你的作品页可以就地建号，名字取的是页面上的**用户名**（如 `aiyafun`）；而你在网页里手填时
写的多半是**昵称**（如 `Aiya哎呀`，把 `Aiyafun` 填在了「平台昵称/ID」里）。两条路径给的名字对不上，
同一个号就成了两个——数据看板按账号分开统计，你会觉得「一半数据不见了」。

- **现在不会再建重**：插件建号时会按「名称 ↔ 平台昵称」交叉比对，认出是同一个号就直接用已有的那个。
- **已经建重的**：到「资产 → 人设与记忆 → 我的账号」，重复的两个号上方会出现一条提示，点「去合并」。
  合并会把选题、草稿、发布记录、每日数据、素材、记忆全部搬到你保留的那个号下，然后删掉另一个；
  保留账号的名称、平台昵称、人设卡不变（被合并那个号的人设卡与版本历史不保留）。
  面板里可以一键调换方向，确认前会先告诉你「将搬过去」哪些数据、各多少条。
  ⚠️ 合并后如果插件里绑的正好是被合并掉的号，去插件的账号下拉框里重新选一次。
- **确实不要的号**：先「归档」，归档后会出现「删除」——输入账号名确认即可彻底删除（不可恢复）。
  灵感会转为工作区共享保留，采集台账作为合规凭证保留，群里绑定到它的机器人会话会解绑。

## 2️⃣ 配飞书机器人 —— 内容推到群，群里也能发指令

**在哪里**：左侧导航「工具 → 模型与设置 → 机器人 / 消息通知」卡片，点「+ 配置飞书机器人」

### 出站推送（2 分钟，推荐先配这个）
把每日选题推荐、热点、合规告警、学习小结自动推到飞书群：

1. 在飞书群 → 设置 → 群机器人 → 添加「自定义机器人」，复制它的 webhook。
2. 粘进设置页，勾选要推的事件，点「保存」→「测试发送」，群里收到就通了。

### 入站 ChatOps（进阶，能在群里发指令）
在群里发链接/文本就收录成选题，发指令驱动引擎。需要在飞书建一个自建应用：

1. 展开设置页「入站 ChatOps」，点「↗ 打开飞书开放平台」建应用，填 App ID / App Secret。
2. 复制页面给的**回调地址**，粘到飞书应用的「事件订阅」里；把飞书给的 Verification Token（和 Encrypt Key）填回来。
3. 订阅事件 `im.message.receive_v1`、开收发消息权限、加机器人能力并发布，把机器人拉进群。

**装好后在群里怎么用：**

| 你发什么 | 机器人做什么 |
|---|---|
| @它 + 一句问题 | 直接对话。带着你的人设、真实数据和长期记忆回答，能接着上一句问 |
| **发文章链接 / 粘一整篇正文** | 抓下正文存进收集箱，回你摘要、要点、以及「这篇对你的账号有什么用」 |
| 直接发短文本 | 收录成选题候选 |
| `/竞对`（或 `/竞对 名字`） | 列出监控中的竞对近期高热作品，**带链接**——把链接甩回群里就能接着拆 |
| `/拆解 竞对作品链接` | 换成拆解视角：它凭什么跑起来（选题角度/标题钩子/结构/情绪）+ 你能借鉴哪一层 |
| `/存 链接或正文` | 明确要剪藏（不想被当成选题时用） |
| `/分析`（或 `/分析 账号名`） | 给账号做一次数据体检：近 30 天发了多少、均量与环比、最好最差、粉丝净增、数据缺口，再给一段反馈 |
| `/问 你的问题` | 明确要对话（怕被当成选题收录时用） |
| `/账号 名字` | 看 / 切换本群当前账号（对话、体检、收录都记到它名下） |
| `/热点` | 看当前热榜 |
| `/选题 关键词` | 把关键词收录成选题 |
| `/采集 竞对主页链接` | 加入竞对监控 |
| `/优化` | 触发一次记忆学习优化 |
| `/重置` | 清掉当前对话上下文，重开一轮（账号绑定保留） |
| `/帮助` | 看指令说明 |

> 收录只进候选池、不自动发布；生成内容仍全程过合规。

**几个说明：**

- **群里必须 @ 它才会应答**，单聊不用。它不会插嘴群里其他人的对话。
- **对话记得住上下文**：同一个群里连着问，「那第二条呢」它接得上；静默一小时后自动重开一轮。
- **多账号工作区它不替你猜**：有两个以上账号又没绑定时，`/分析` 会先问你是哪个号，而不是随便挑一个——挑错了数据就记到别人名下了。
- **没有数据不编分析**：账号还没有任何发布/回填数据时，它直说没有并告诉你去哪补，不会对着空数据生成一段像模像样的结论。
- **发监控中竞对的作品链接会自动切成「拆解」视角**：同一篇文章，「我该学什么」和「它凭什么火」问的不是一件事。
- **剪藏存的是他人作品正文**：只落在你自己的工作区，仅供你分析参考；它**不会**进入「像我一样写」的语料池
  （有测试钉死这条），也别直接复用原文文字——那是洗稿。
- **群里放开哪些操作由管理员决定**：「工具 → 机器人与通知 → 编辑机器人 → 群里允许哪些操作」。
  群成员都能触发机器人，所以 `/分析`（会把粉丝数、播放量发到群里）和 `/问`（会消耗 AI 额度）这两项
  在设置里带 ⚠ 标注；不想让群里所有人都能用就取消勾选。默认全部开启，`/帮助` 永远可用。

## 3️⃣ 让记忆越用越懂你 —— 持续学习优化

**在哪里**：左侧导航「资产 → 人设与记忆 → 持续学习与优化」卡片

- 系统每天自动优化一次记忆（去重、让反复验证的结论生效、给老旧观察降权遗忘）。
- 想立刻优化，点卡片里的「⚡ 立即优化记忆」。
- 下方会给出**人设改进建议**——只是建议，改不改由你，去上方「人设卡」点编辑自行采纳。

## 4️⃣ 看懂每天的选题推荐

**在哪里**：左侧导航「选题 → 选题引擎」

### 推荐按「什么时候做」分三队，不是按分数排一长条

| 队列 | 含义 |
|---|---|
| ⚡ 今日突击 | 有时间窗口，过期作废——今天不动手就没了 |
| 📆 本周窗口 | 有节奏但不紧急，适合排进本周产能 |
| 🌲 常青储备 | 不依赖热点，什么时候做都成立；没头绪或产能有空档时用 |

> 综合分回答「值不值得做」，队列回答「先做哪个」——两件事，不互相顶替。

### 每条卡片上的三样东西

- **差异化切入角**：AI 给的创意，一句话说清怎么避开同质化。
- **为什么推给你**：查你的数据查出来的**事实**（哪条旧作跑赢过、话题几点在哪上的榜）。
  它和切入角分开放，就是为了让你分得清哪句是创意、哪句是证据。
- **作战卡**（点开折叠）：同行做过的参考样本、你自己的最佳发布时段、近 72 小时的竞争密度、
  你在该平台的真实水位。**只放事实，不给预测**——不编「预计播放多少」这种数。

### 推荐从哪儿来（卡片左上角的徽标）

| 徽标 | 含义 |
|---|---|
| 来自热点 | 当前热榜在榜话题 |
| 来自竞对 | 你订阅的同行的高热作品 |
| 抢跑窗口 | 话题已在别的平台爆了、你的主战平台还没有——赶在前面做 |
| 旧文翻新 | 你做过同题内容，这个话题又重新上榜了 |
| 跨平台补发 | 你在某平台的爆款，还没发到其他主战平台 |
| 节点日历 | 618、开学季这类每年确定会来的流量节点，赢在提前量 |
| 常青题 | 赛道里常年有人问的话题，没热点的日子靠它 |
| 灵感箱 | 你自己存进收集箱的内容，和从评论里挖出来的读者提问 |

还会看到**「蓝海」**标：这个话题在榜上活得久、跨平台扩散广，而你监控的同行还没怎么做。
它算的是站内可观测的信号（在榜时长 × 扩散平台数 × 竞对同题密度），**不是全网搜索指数**。

多人工作区里，每条推荐下面还有「想做 / 不想做」的团队投票。
**票数只用于协调，不影响综合分与排序**。

## 5️⃣ 把转瞬即逝的念头存下来 —— 灵感收集箱

**在哪里**：左侧导航「选题 → 灵感收集箱」

1. 刷到值得记一笔的内容，用采集助手的「收进灵感箱」一键存下来；也可以在页面上手动记。
   **备注那栏最有用**——有备注时系统会拿你写的那句话当选题，而不是原标题。
   这个按钮在插件里**任何网页上都在**（弹窗、SidePanel、页内侧栏三处都有），
   不像「加为竞对」「回填我的作品」那样要挑平台——在一个插件采不了数据的站点上刷到好东西，
   记一笔正是当下唯一该做的事。也可以直接**选中一段文字右键**「收进烽火台灵感箱」，
   选中的那段话会自动进备注栏。
2. 点「从评论里挖问题」，把评论区的文字整段粘进去，系统只挑出**提问句**存起来。
   被问得越多的问题，越值得做成内容。
3. 存进来的东西会**主动参与每天的推荐**：撞上热点时它会带着「你 3 周前收藏过这个」一起推给你；
   没撞上就自己进「本周窗口」。变成选题被采纳后自动出队，不会重复出现。

> 挖问题时**只保存提问句本身**，不保存作者、昵称，也不保存其它评论正文。

### 拆解一条作品（视频/图文都行）

两种拆法，**产出的报告长得一样，差别只在「看到了什么」**——报告顶部会写明这一条：

| | 怎么用 | 看得到 | 拿得到 |
|---|---|---|---|
| **画面级** | 「内容资讯库」页 →「拆解一条视频」→ 上传视频文件（25MB 内）| 逐帧画面 + 画面里的硬字幕 | 开头钩子 + **画面时间线**（0:00-0:05 画面上发生了什么）+ 爆点 + 对你的用处 |
| **口播级** | 在作品页上**右键 →「一键拆解这条作品」** | 封面图 + 文案 + 指标 + **平台字幕轨** | **口播时间线（原文带时间戳）** + 开场怎么说 + 爆点 + 对你的用处，**没有画面时间线** |

⚠️ **两者是互补不是替代**：上传能看到画面看不到口播（豆包视频理解只抽帧读画面、**听不到声音**），
插件能拿到口播原文却看不到画面。想两样都要，就两条都跑一遍。

字幕轨目前 **YouTube / B站** 已接通（读的是平台自己的字幕，需要你在那个平台已登录）；
抖音、小红书等有没有字幕轨要看具体作品，没有就自动降级成只看封面和文案。

⚠️ **插件为什么拿不到视频**：作品页上的播放流是加密分片的，播放地址还带鉴权和防盗链——
我们**不去解也不去绕**（和「不绕过任何反爬」是同一条线），更**不会替你自动下载别人的视频**。
要画面级拆解，请你自己把视频下载下来再上传。抖音/B站/小红书/YouTube 的**作品页链接直接贴也不行**，
那是网页不是视频文件。字幕轨则不同——它是平台公开提供、你在页面上本来就看得到的文本，插件读它不越任何线。

⚠️ **视频拆解要用你自己的火山方舟 API Key**（设置 → 模型渠道 → 加「火山引擎 豆包」，
模型名填 doubao-seed 系列或带 vision 的型号）。一次视频推理抵几十次文本调用，这笔钱平台不垫付。
没配的话卡片是灰的，会直接告诉你去哪配。

拆解结果和剪藏一样进「内容资讯库」，同样**不会**进入「像我一样写」的语料池——只供你自己分析，
别直接复用别人的文字和画面。

## 6️⃣ 看什么样的内容在你账号真的跑得动 —— 爆款基因

**在哪里**：左侧导航「资产 → 爆款基因」

- 按**选题来源 / 平台 / 发布时段 / 切入角**四个维度，算出你已发布内容的真实胜率。
- 胜率 = 该类里跑赢你同平台均播的条数 ÷ 该类总条数，**每个数都能自己验算**。
- **不足 3 条的类别只报条数、不报胜率**——2 条里赢 1 条不是 50% 胜率，是没有结论。
- 要让「选题来源」和「切入角」两维有数据，发布时需要带上选题归因——
  也就是从选题引擎采纳、再去创作工坊做出来的内容。

## 7️⃣ 在创作工坊写出不像 AI 写的东西

**在哪里**：左侧导航「创作 → 创作工坊」

### 起稿不一定要从选题开始

右上角「新建草稿」有三条路：

| 模式 | 什么时候用 | 会发生什么 |
|---|---|---|
| 粘一段我写的 | 你已经写好了，想让系统帮你打磨 | 存成**人工原稿**（第 1 版），同时进入你的文风样本池 |
| 一句话想法 | 脑子里有个念头，还没动笔 | 按你的人设/素材/文风展开成一版初稿（消耗一次 AI 额度） |
| 空白稿 | 就想自己写 | 只建个壳 |

> 以前只能「先去选题中心采纳一个选题」才能建草稿。在改写框里写完复制走人，
> 系统就学不到任何东西——不留版本、不学口味、不进发布登记、数据也回不来。

### 想让 AI 写得像你，就喂它你写过的东西

到「资产 → 素材库」加几条 **文风样本**：整段贴你自己写过的稿子（200 字以上效果最好）。
之后所有生成都会照着那个语感写。

这比在人设里写「语气：幽默」有用得多——「幽默」是把你的文风压成一个所有人共用的形容词，
模型收到它只能给你**它理解的平均幽默**，那正是「AI 味」的来源。原文样本是无损的。

样本池按这个顺序取（最多 3 条，同平台优先）：

1. 素材库里的「文风样本」（你明确指定的）
2. 你登记发布过的正文
3. 你自己改定过的终稿

> 提示词里写死了「**只学怎么说，不要抄内容**」——样本里的经历和数据不会被搬进新稿。

### 深度模式：想清楚说什么，再想怎么说

起草时（「AI 生成初稿」旁边、以及新建草稿的「一句话想法」里）可以勾**深度模式**。它把生成拆成两步：

1. **只列要点大纲**——钩子点、3-5 个要点、结尾落点。写成短语，故意写得很干；
2. **照着你的原句样本把大纲写成成稿**——这一步信息已经定死了，模型的全部注意力用来学你的语感。

为什么要拆：一次生成里，模型要同时决定「说什么」和「怎么说」，这两件事抢注意力，
而它的默认解法是先保证内容说全，于是表达一律回落到它最熟的那套平均文风——那就是 AI 味。

**代价是两次 AI 调用**（两次额度），所以它是你自己勾的选项，不是默认。什么时候值得勾：
稿子要正式发、或者你已经在素材库放了文风样本。随手起个草稿就别勾了。

> 两条内部纪律：第二步**不许新增大纲里没有的事实**；如果第二步没跑成（比如额度刚好在两步之间用尽），
> 大纲会被存成一版留给你——第一步的钱已经花了，不能让你两手空空。

### 人味体检 + 一键去 AI 味

编辑框下方除了「算法教练」，还有一张**人味体检**（确定性规则，不花 AI 额度）：

- **套话密度**：命中「值得注意的是 / 综上所述 / 让我们一起」这类大模型高频词
- **句子节奏**：句长是不是几乎一样长（人说话忽长忽短，模型不会）
- **段落节奏**：段落是不是等长
- **对仗密度**：「不仅…而且 / 不是…而是」这类句式的密度
- **口语碎句**：口语平台上有没有半句话式的短句（公众号/知乎这类长文平台不判这项）

不满意就点「**一键去 AI 味**」：它按你的原句样本换一种说法，**信息一个不加、一个不减**，
并给出人味分前后对比。

> **不足 120 字或不足 5 句不出分**。那么短算不出句长方差，给一个 73 分只是拿噪声骗你。

### 标题矩阵 + 封面建议

正文定稿后点「生成标题矩阵 + 封面建议」，一次给 6 个**角度互不相同**的标题：
结果前置 / 悬念缺口 / 反常识 / 身份指向 / 数字清单 / 痛点提问。

每条附长度诊断（小红书 20 字是硬上限，超了会被截断）、套话检测和「有没有具体数字」提示；
**命中合规红线的标题直接被拦下，不展示也不能复制**。封面给主文案/副文案/画面建议——
任一条标题、封面建议都可以一键「作封面大字」填进上面的封面工位。

### AI 封面（多平台比例）

「标题与封面」tab 顶部就是封面工位，当前草稿条「写完之后」一排的「🎨 封面」也会跳到这里：

- **比例不用选**：按草稿平台自动定——小红书 3:4、视频号 6:7、抖音/TikTok 9:16、B站 16:10、公众号 2.35:1、
  YouTube/X 16:9；要别的比例可以换。
- **大字不用想**：默认用你「用这条」采纳的标题；留空则从正文自动提炼（多花一次 AI 名额）。超过 14 字会提醒「上图会挤」，不会替你截断。
- **风格按赛道推荐**：十几种风格，人设赛道命中的排前面并标「推荐」，每种一句「适合谁」。「更多选项」里可调字体倾向、装饰点缀、给 AI 的备注。
- **可带你的脸**：上传 1 张人像/主体照 + 最多 2 张背景图，封面会「主体保真」。上传前要**勾选确认**照片是本人或已获单独同意；
  照片在浏览器里先压到 1MB 以内，只随本次生成发给火山引擎方舟（即梦）出图，**默认用完即弃**（不落库、不落盘）。
  勾「存进我的形象」才会加密保存下来（每个工作区最多 20 张），下次直接勾选复用、不用重传，随时可删。不传照片也能出图。
- **出过的封面还在**：工位下方「本稿封面（N）」列出这篇稿子出过的封面，刷新、隔天回来都还在（自动保留 90 天 / 最近 50 张）；
  点「设为本稿封面」选定一张，选定的那张不会被自动清理。「一稿多平台」的家族列表里每篇都标了「封面：未出 / N 张」。
- **默认风格可以固定**：在「人设与记忆 → 品牌视觉」里设默认封面风格与字体倾向，之后每次打开工位就是它。
- **出图即带标识**：图上有「AI 生成」水印（不能关），文件里写了隐式 AIGC 元数据（PNG / JPEG 都有）；预览、下载、右键另存拿到的是同一份。
- **换一张 / 换风格**只重出图，不再重抽文案，只花一次名额。「文字留白版」不上字，给你自己叠字用。

需要一个「火山引擎 豆包」渠道（设置 → 模型渠道）；已经为视频/文本加过豆包 Key 的用户零配置直接用。
图像有单独的每日张数上限，按钮旁会显示「今日还能出 N 张」。

### 一稿多平台

同一篇要发几个平台，用「一稿多平台」派生：每个平台生成一份**独立草稿**
（各自版本线、各自登记发布、各自回流），彼此认亲。
等两个以上平台都发布并回流数据后，这里会告诉你**同一篇内容在哪个平台跑赢了**。

一次最多 3 个平台，每个平台消耗一次 AI 额度；已经有同源版本的平台会自动跳过。

### 技能：本次要求 + 用第几版

- 技能永远基于**最新一版**正文运行，结果卡上写明「基于第 N 版」。
- 技能按平台分组，当前草稿平台的排在前面；点到别的平台的技能会先确认。
- 展开「本次要求」可以指定这一次的**篇幅 / 语气 / 要用上的哪几条素材 / 一句话补充要求**——
  这些只影响这一次，不会改掉账号的长期设定。
