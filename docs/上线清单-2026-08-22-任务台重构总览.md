## 上线前排查修掉的（2026-08-23，都在代码里，不需要额外 SQL）

与 `tests/fake-green-guard.test.ts`（把假绿探测固化成常驻守卫）。

| # | 症状 | 真因 |
|---|---|---|
| 1 | 追问那句话**人间蒸发** | `drainNotes` 标成「已送达」之后才落库，中间那次模型调用一抛错（配额超限最常见）就两头都找不回来 |
| 2 | 点了终止**子任务还在做** | 父运行 cancelled 了，它派出去的子运行是另一条独立后台线，接着烧额度接着写库 |
| 3 | 智能体流水线**永远转圈** | `kickWorkflowRun` 是 fire-and-forget，既没租约也没人接手；进程一重启那行永远停在 running |
| 4 | 只派过一次却说「已经用过 2 次」 | 挂起类调用会写**两条** `tool_result`（挂起时一条、叫醒补结果一条），按它记账把上限腰斩 |
| 5 | 续跑时挂着**上一段的答案** | `answer: undefined` 被 Prisma 整个忽略，得写 `null` |
| 6 | 时间线上同一个结果**出现两遍** | 叫醒的流水写在 `transition` 之前，第二次叫醒 transition 落空但流水已经写下去了 |

⚠️ 第 3 条新增了一件定时兜底（`tickAgentRuns` 的第 ⑤ 件）：两小时没心跳的流水线如实判死，
并把等它的 AI 执行一并叫醒。**它不接手重跑**——半截流水线重来会把已做过的步骤再做一遍。

## 关于 `WorkflowTemplate.persona`（先前误报成阻塞项，更正）

`prisma/postgres/` 里确实没有任何一份 SQL 加过 `persona` 列，但**这不是缺口**：

- **新装**走 `scripts/db-init-supabase.sh`，第一步就是 `prisma db push`（直接照 schema 建全），
  SQL 目录只负责 RLS / 扩展 / 索引。
- **存量升级**走 `scripts/deploy-gate.sh`，它跑 `prisma migrate diff --from-url <生产库>`，
  任何漏列都会被列出来并给出可直接执行的 SQL。

也就是说 `prisma/postgres/` **本来就不是完整的建库记录**，别照它去核对列。

## 部署后先确认三件

1. **worker 日志里有两条队列**：`beacon-jobs(并发 4) + beacon-agent(并发 4)`。
   AI 执行的 loop 一跑就是几十分钟，与采集/定时共用槽位的话，

   它是「等额度的接着跑、跑飞的接手、挂太久的收尾、排队的往前挪」四件事的唯一兜底。
3. 派一次活，看**任务视图**上有没有：实时步骤流、产物清单、「这次用了 N 次 AI 调用」。

## 这次重构改变了什么（一句话版）

| 批 | 改了什么 | 用户能感觉到的 |
|---|---|---|
| 0 | 状态迁移收口 `transition()` | 点了终止就是终止；额度用完会自己接着跑；不再有永远转圈的任务 |
| 1 | 队列与通知 | 派多了会排队而不是一起烧额度；跑完了有通知 |
| 2 | 授权三档 | 可以「一次授权、一口气跑完」，签合约那几样仍然逐个问 |
| 3 | 追问与续跑 | 跑着跑着能补一句；跑完不满意能接着说，不用从头再派 |
| 4 | 自主智能体 + 产物清单 | 智能体可以「给它目标自己安排」；做出来的东西点得进去 |
| 5 | 一键任务 | 反复要做的事存成卡，点一下就派；挂定时就是无人值守 |
| 6 | 打磨 | 看得到花了多少；对外调用能终止；红点不再为别人的事亮 |

## 几条不许走反的规矩（改这块代码前先读）

- **状态只能经 `transition()` 改**（乐观锁）。通知、叫醒父运行、提拔排队、
  回写定时成败全挂在它上面——绕过它 = 那几件事静默失效。
- **确认闸靠 `write:true` 机制不靠提示词**；`contract` 工具（建发布计划/写记忆/配定时/拼智能体）
  任何授权档下都要人点头。
- **对外调用面永远没有确认接口**，且 `origin='api'` 在 `startAgentRun` 里**强制**回落最保守档。
- **自主智能体三条**：工具白名单取交集、授权档不超过父、嵌套只许一层。
- **加新的挂起类型要同时做三件事**：终态时叫醒、`settleIfResolved` 加分支、想清楚到期时间。
- **加新状态必须收编进 `LIVE_STATUSES`**，否则终止不了它、权限重建拒载它、租约抢不到它。
