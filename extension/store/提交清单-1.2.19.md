## 1. 本次变更（1.2.19，给审核备注/自己记）

**权限声明：`permissions` / `host_permissions` 与在架版本相比零变化。**
微博 / 快手 / 知乎 / 头条 / 百家号五个配方平台**不进安装权限**，走早已声明的 `optional_host_permissions`
按需单站点授权（用户在弹窗点击时由浏览器弹确认，随时可在扩展页撤销）。

1. **创作者后台自动回填扩到内置四个后台**：视频号 / 抖音 / 小红书 / B站加入「每天自动回填我的后台数据」
   （仍默认关闭；只开用户登记了账号的后台；停在登录页就停止，不替用户登录）。此前只有公众号可选模块能自动回填。
2. **工作区可派「回填我的创作者后台」**：白名单里这一项此前没有可派的路，现在真的能派（新 kind `collect_self_backend`）。
3. **「回填我的主页」加 YouTube**：频道页公开、不用登录。
4. **五个大陆平台按内置配方采竞对主页**（新 kind `collect_competitor_recipe`）：服务端下发规则，插件按规则读已渲染的公开页；
   首次要对该站点授权一次；只补已订阅竞对，不建档。
5. **发布填充 / 评论读取 / 创作者后台行识别接入解析自学习**：手写选择器落空时上传脱敏骨架（与已披露的「解析失效时的结构样本」同一条链，
   新增三个 scope），服务端学出的规则当天下发。发布按钮**不**用学来的规则点，仍只认文字。
