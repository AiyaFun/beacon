## 名称
烽火台采集助手

## 简介 / Summary（≤132 字符）

## 详细描述 / Description

烽火台采集助手是「烽火台 · 跨平台内容作战室」的配套浏览器插件，帮内容创作者与团队把**你亲眼可见的公开数据**顺手收进自己的作战室。

**它能做什么**
- 竞对补数：打开你已订阅竞对的公开主页（B站空间页 / 抖音用户页 / 小红书用户页），插件把页面上已渲染的公开数据（作品列表、粉丝数）一键回传到烽火台竞对档案。
- 深度指标：在单条内容详情页，把评论、收藏、分享、投币、弹幕等只在详情页可见的指标补进作品档案。
- 自有回填：在你自己已发布的作品页，一键把播放/点赞/评论等公开表现数据回填到数据看板。
- 每日提醒：在图标上以角标提示「今日待刷新数」，提醒你去看，不替你抓。

**合规设计（我们认真对待）**
- 只采公开主页上已渲染、你亲眼可见的 DOM，不碰登录态接口。除当场点击外，另有一项**默认开启**的每日定时采集：在你设定的时间用后台标签页逐个打开你已订阅的竞对公开主页，采完立即关闭，可在设置里关掉。
- 最小主机权限：只申请 B站/抖音/小红书/X/YouTube/TikTok 六站的**公开作品页**（8 条路径，0.8.2 起，为了让「读评论提问」在页内侧栏也能用）。**不含任何创作者后台域名**；回传本身不依赖主机权限，走服务端 CORS + 令牌鉴权。
- 他人/竞对只采已公开发布的账号与作品信息，不碰非公开数据；你**自己**的作品另算——在你本人已登录的创作者后台里读你自己作品的表现数字（含完播率/完读率），只回传到你自己的工作区。两种情况都不托管、不上传任何平台凭证。
- 采集令牌只授权「向你自己的工作区补充已订阅竞对的公开数据」这一件事。

**需要配合**
需先注册烽火台账号并在「设置 → 数据源 → 插件采集令牌」生成令牌填入插件。插件本身不采集、不上传任何与烽火台账号无关的数据。
